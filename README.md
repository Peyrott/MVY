# 🚀 Projetos

## ⚽ Peladas

Plataforma web para **aluguel de quadras esportivas** (futebol, vôlei, futsal, etc).

### 🎯 Objetivo
Facilitar a reserva de quadras esportivas e a organização de partidas entre amigos, conectando usuários a estabelecimentos que disponibilizam quadras para aluguel.

### ⚙️ Funcionamento
- Usuário busca quadras disponíveis na região
- Realiza a reserva online
- Pagamento direto pela plataforma
- A plataforma cobra **20% de comissão sobre o valor do aluguel**

### 🧩 Funcionalidades
- Cadastro de usuários
- Cadastro de quadras
- Sistema de reservas
- Pagamento online
- Avaliação de quadras

### 🛠️ Stack sugerida
Frontend:
- HTML
- CSS
- JavaScript
- React

Backend:
- Node.js
- Express

Banco de dados:
- PostgreSQL ou Supabase

Outros:
- Stripe ou Mercado Pago (pagamentos)

### 🗺️ Roadmap
- [ ] Cadastro e login de usuários
- [ ] Cadastro de quadras
- [ ] Sistema de busca por quadras
- [ ] Sistema de reservas
- [ ] Sistema de pagamento
- [ ] Avaliações e comentários

# 🔧 PauParaTodaObra

Plataforma inspirada em serviços como **GetNinja**, voltada para profissionais de serviços domésticos e gerais.

### 🎯 Objetivo
Conectar pessoas que precisam de pequenos serviços com profissionais disponíveis na região.

### 👷 Serviços incluídos
- Marido de aluguel
- Corte de grama
- Limpeza de pátio
- Pequenos serviços de encanação
- Serviços elétricos simples
- Pequenas reformas
- Outros serviços domésticos

### 🧩 Funcionalidades
- Cadastro de clientes
- Cadastro de profissionais
- Busca por tipo de serviço
- Sistema de avaliações
- Chat entre cliente e profissional
- Sistema de orçamento

### 🛠️ Stack sugerida

Frontend:
- React
- Tailwind CSS

Backend:
- Node.js
- Express

Banco de dados:
- PostgreSQL

Outros:
- API de geolocalização
- Sistema de avaliação

### 🗺️ Roadmap
- [ ] Cadastro de usuários
- [ ] Cadastro de profissionais
- [ ] Busca por serviços
- [ ] Sistema de solicitação de serviço
- [ ] Sistema de avaliação
- [ ] Chat entre cliente e profissional

# 📊 EconomIA

Plataforma web de **controle financeiro pessoal com auxílio de inteligência artificial**.

### 🎯 Objetivo
Ajudar usuários a entender melhor seus hábitos financeiros, controlar gastos e atingir metas financeiras.

### 🧠 Funcionalidades
- Registro de receitas e despesas
- Classificação automática de gastos
- Análise de padrões de consumo
- Definição de metas financeiras
- Relatórios e gráficos
- Sugestões de economia baseadas em IA

### 🔮 Funcionalidades futuras
- Integração com bancos
- Sugestões de investimento
- Compra e venda no mercado financeiro
- Planejamento financeiro automático

### 🛠️ Stack sugerida

Frontend:
- React
- Chart.js ou Recharts (gráficos)

Backend:
- Python (FastAPI ou Flask)

Banco de dados:
- PostgreSQL

IA e análise de dados:
- Python
- Pandas
- APIs de IA

### 🗺️ Roadmap
- [ ] Sistema de cadastro e login
- [ ] Registro de receitas e despesas
- [ ] Classificação de gastos
- [ ] Dashboard com gráficos
- [ ] Análise de padrões de consumo
- [ ] Sugestões inteligentes de economia
